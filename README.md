# AI Governance Audit Readiness Scorer

A single-page app in one file (`index.html`) with no dependencies. It's the companion tool for an edition of the LinkedIn newsletter **AI in Finance, Done Right**: **"1.4 Trillion Journal Lines, 130,000 Auditors, and a 5% PCAOB Rate: Inside EY's Global Agentic AI Rollout"**.

## Features
- **Tab 1, Agent inventory:** List the AI agents or tools your finance team uses and tick what applies: ICFR-relevant accounts, posting without approval (counts double), customer or personal data, external reporting. Each agent gets a High, Medium or Low tier, with the evidence auditors are likely to ask for at that tier.
- **Tab 2, 90-day readiness:** Eight controls: standardized process, narrow permissions, certification, drift monitoring, approval gates, data isolation, exception logs and a human review trail. You get a readiness dial, a 90-day plan split into three 30-day phases, and a memo you can copy.

Tiers and scores are planning aids, not an auditing standard. The demo list is made up. Everything runs in the browser and nothing is uploaded.
